# Vidyutha S.P — Personal Portfolio Website

A modern, visually impressive, and professional portfolio website created for **Vidyutha S.P**, a 2nd-year B.E Computer Science Engineering student at **Sathyabama Institute of Science & Technology, Chennai** (2025–2029).

Built with a futuristic dark theme, glassmorphic cards, subtle glowing purple/blue/pink accents, interactive constellation physics, and authentic, genuine presentation.

---

## 🌟 Key Features

- **Hero Section**: Pulsing active undergrad status indicator, bold headline *"Building my way into the world of technology"*, interactive CTAs, direct social links, and a futuristic code-card widget.
- **About Me**: Genuine, humble, and ambitious narrative highlighting college background, curiosity about systems, and passion for problem-solving.
- **Skills Matrix**: Categorized into *Programming*, *Computer Science*, *Technology Interests*, and *Tools*, framed honestly as active learning and development.
- **Featured Projects**:
  1. *Legal Metrology Packaged Commodities Compliance Scanner* (AI, OCR, and rules engine concept).
  2. *Muscle Munch* (High-protein Indian-style nutrition and consumer snack concept).
  3. *More Projects Coming Soon* (Roadmap and future development radar).
- **Interactive Project Modal**: Displays detailed problem statements, architectural notes, and technology breakdowns.
- **Education Section**: B.E Computer Science Engineering at Sathyabama Institute of Science & Technology, Chennai (2025–2029) with core coursework chips.
- **Learning Journey**: Visual interactive roadmap tracing:
  `C Programming` → `Java` → `Data Structures` → `Computer Architecture` → `Theory of Computation` → `AI/ML` → `Cloud & Emerging Technologies`.
- **Career Vision**: *"Learn. Build. Lead."* — detailing continuous skill mastery, practical software creation, and collaborative leadership.
- **Contact & Interaction**: 1-click "Copy Email" with instant toast feedback, direct LinkedIn profile connection, and a contact message composer.
- **Zero-Dependency Architecture**: Runs in any browser right out of the box with pure semantic HTML5, modern CSS3 (with CSS variables and backdrop-filter), and Vanilla JavaScript.

## 🌐 Instant Free Hosting (Deployment)

### Option 1: GitHub Pages (Recommended)
1. Initialize git and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Vidyutha's portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Source**, select `Deploy from a branch` -> `main` branch -> `/ (root)` folder -> click **Save**.
   - Your site will be live at `https://<your-username>.github.io/<repo-name>/` in 60 seconds!

### Option 2: Vercel or Netlify
- Drag and drop the `cs-portfolio` folder directly into [app.netlify.com/drop](https://app.netlify.com/drop) or [vercel.com](https://vercel.com) for instant SSL deployment with zero build setup.
